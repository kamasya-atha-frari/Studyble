# Studyble

React Native (Expo) mobile application for peer study tailored for students, featuring live study rooms, public chat & live question voting, Q&A threads, and persistent local storage.

## Tech Stack
- React Native + Expo SDK 58 + TypeScript
- React Navigation (`@react-navigation/native`, `@react-navigation/bottom-tabs`, `@react-navigation/native-stack`)
- `@react-native-async-storage/async-storage` for local persistence

## Key Features
- **Live Study Rooms & Live Room View**: Filter rooms by category (`General`, `Major`, `Course`, `Interest`), join a room to enter the live view, track focus timer blocks, and earn session points.
- **Live Public Chat & Question Voting**: Post questions or public chat messages inside a live room and upvote questions so top questions surface first.
- **Peer Q&A**: Browse study questions, upvote posts, open thread details, and submit answers.
- **Profile & Settings**: View study points, level progression, completed sessions, display name, default focus duration, and reset demo data.
